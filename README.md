# 얼굴 벽

태블릿이나 휴대폰에서 얼굴과 한마디를 손으로 그려 보내면, 노트북 벽 화면 가운데에서 그려지며 나타나는 행사용 페이지예요. 로그인 없이 링크만 열면 됩니다.

- 벽 화면: https://linklab08-source.github.io/face-wall/#wall
- 그리기 화면: 벽 화면에 뜨는 QR을 찍거나, https://linklab08-source.github.io/face-wall/#pad 에서 방 코드를 넣어요.

그림은 공개 MQTT 중계 서버(broker.emqx.io, broker.hivemq.com)를 거쳐 벽으로 전달되고, 벽 화면 브라우저에 저장됩니다.
